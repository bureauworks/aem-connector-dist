# wxrks AEM Connector — Distribution Package

This repository hosts the **distribution artifacts** for the wxrks AEM Connector. It serves as the Maven package registry where release builds are published and made available for consumption by Adobe Experience Manager (AEM) environments.

> **This is not the source code repository.** This repo only contains the packaged release artifacts deployed via GitHub Packages.
